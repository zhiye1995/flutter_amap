# Android_3D_Demo

因官方示例代码长期未更新，Gradle版本过低，为了节省每次下载demo之后的工作，特创建此项目。主要更新如下：  
1.升级Gradle版本  
2.增加签名文件  
3.设置高德SDK key，运行App可以直接看到效果，避免经常申请key  
4.替换switch为if-else写法，否则无法编译
